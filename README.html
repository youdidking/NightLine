۲.۶.۳ — revised

بازنشانی با حفظ دسترسی‌ها و بکاپ هش‌دار؛ آپدیتر دارای بکاپ/rollback و تأیید هش یا امضای pin‌شده؛ کارگاه چندکانفیگی با خروجی‌های client-specific، batching مصرف و تاریخچه واقعی ۷/۳۰ روزه. قالب ساخته‌شده تضمین اتصال اینترنت ایران نیست.

راهنمای revised و مرز پشتیبانی

حفظ مصرف در خطای نوشتن و تلاش مجدد؛ ذخیره‌سازی مرکزی SQLite اختیاری و خطای تغییر هم‌زمان؛ فایل‌های عمومی کش‌پذیر و subset اجباری فونت؛ CI و تست‌های جدید.

نصب‌کننده و Pages همچنان KV و best effort هستند. فعال‌سازی مرکزی روی Worker نیاز به مهاجرت دستی دارد؛ مصرف ارسال‌نشده در RAM در برابر crash تضمین ندارد. پیش از مهاجرت فایل docs/CENTRAL_STORAGE_FA.md را بخوانید و Backup بگیرید.

01 / ORGANIZE

هشت بخش، بدون ازدحام

اشتراک، مشترکین، کارگاه، اتصال، آزمایشگاه، مسیریابی، مشاور و امنیت؛ امکانات مرتبط کنار هم قرار دارند.

02 / MEASURE

از مرورگر خودتان

بررسی DNS over HTTPS و IP عمومی با مهلت و هم‌زمانی دلخواه، توقف، فیلتر و خروجی نتیجه.

03 / UNDERSTAND

نتیجهٔ قابل فهم

سبز برای پاسخ معتبر همان آزمون، نارنجی برای سیگنال محدود و قرمز برای آزمون تأییدنشده؛ خطا پینگ موفق نمی‌شود.

04 / CREATE

کارگاه WARP

ثبت رسمی یا ورود حساب، WireGuard و MASQUE، تنظیمات سازگار AmneziaWG و متن قابل ویرایش، کپی و دانلود.

05 / EXPERIENCE

روشن، تاریک، متحرک

میان‌برهای گرافیکی، نمودار نمونه‌ها، رنگ‌های وضعیت و حرکت‌های سبک؛ کاهش انیمیشن و صفحه‌کلید پشتیبانی می‌شوند.

06 / KEEP

امکانات اصلی باقی‌اند

VLESS/Trojan، مصرف و اعتبار، کشور تقریبی، ProxyIP و خروجی زنجیره‌ای، DNS خصوصی و بروزرسانی داخل پنل.

نصب و ارتقا

  1. نصب‌کننده را باز کنید؛ Workers یا Pages را انتخاب کنید.
  2. فقط توکن Cloudflare را طبق راهنمای همان صفحه بدهید؛ توکن GitHub لازم نیست.
  3. پیشرفت و نتیجه را در همان صفحه ببینید؛ آدرس و رمز را امن نگه دارید و توکن نصب را لغو کنید.
  4. کاربر بسازید و لینک مناسب برنامه یا QR را به او بدهید.

برای ارتقا پشتیبان بگیرید و همان پروژه و فضای KV قبلی را حفظ کنید. رایگان‌بودن پنل به معنی منابع نامحدود Cloudflare نیست.

ابزار HTML؛ بدون نصب برای DNS و HTTPS

  1. فایل NightLine-Network-Lab.html را در مرورگر کامل باز کنید؛ یا به تب آزمایشگاه پنل بروید.
  2. بخش DNS یا IP را انتخاب کنید؛ فهرست، مهلت و هم‌زمانی را تنظیم کنید.
  3. اجازهٔ ارسال درخواست را تأیید و شروع را بزنید. صرفاً بازکردن فایل آزمونی اجرا نمی‌کند.
  4. نتایج را فیلتر، مقصدهای معتبر را کپی یا JSON را دانلود کنید. داخل پنل می‌توانید IPهای معتبر را با تأیید خودتان به فهرست اضافه و ذخیره کنید.
پاسخ معتبرسیگنال محدودتأییدنشده

اعداد ICMP یا UDP/53 نیستند. TLS، CORS، کش، VPN و استفادهٔ مجدد اتصال روی نتیجه اثر دارند؛ سبز هم تضمین اتصال تونل نیست. پیش‌نمایش محدود ممکن است شبکه نداشته باشد؛ فایل را دانلود کنید.

WireGuard؛ محدودیت مرورگر را پنهان نمی‌کنیم

HTML معمولی نمی‌تواند handshake دلخواه UDP به WARP بفرستد. بخش WireGuard، گزارش ابزار محلی Node.js خودتان را می‌خواند؛ این گزارش پینگ مرورگر یا گواهی مستقل نیست. راهنما در tools/README_FA.md قرار دارد؛ ابزار به Python یا نصب درایور نیاز ندارد و کلید خصوصی روی سیستم خودتان می‌ماند.

در پنل، بهترین مقصد گزارش محلی را می‌توانید به حساب WireGuard بارگذاری‌شده اعمال کنید. موفقیت یک handshake، سرعت، پایداری یا عبور کامل اینترنت را اثبات نمی‌کند. MASQUE در این آزمون نیست.

نمای واقعی ابزار در حالت تاریک

تصویر اجرای رابط در آزمون کنترل‌شده؛ نه تصویر شماتیک و نه تضمین زمان پاسخ شما.

نکته‌های ضروری

  • فایل حساب، لینک اشتراک، رمز و پشتیبان محرمانه‌اند.
  • کلید کارگاه حافظه‌ای است؛ پیش از بستن تب پشتیبان بگیرید.
  • فایل WARP مستقل از سهمیه و انقضای Worker است.
  • فایل AmneziaWG را در WireGuard معمولی وارد نکنید؛ Fragment کارگاه فقط برای MASQUE/H2 است.
  • کشور IP ورودی، تضمین کشور خروجی نیست؛ IP خالی خروجی ثابت نمی‌سازد.
  • هیچ تنظیم یا فهرست IP، اتصال دائمی در ایران یا رفع خطای CPU پلن Free را تضمین نمی‌کند.
