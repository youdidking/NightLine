رادار اتصال شما

از همین مرورگر، روی همین اینترنت. بدون واسطهٔ Worker و بدون ارسال کلید حساب.

تأخیر پاسخ واقعی DNS over HTTPS

سه درخواست با پاسخ DNS معتبر؛ زمان HTTPS + پردازش DNS، نه پینگ ICMP یا UDP/53. نتیجه ممکن است از کش ریزالور باشد. درخواست‌ها به ریزالور انتخابی می‌روند و آن سرویس دامنهٔ پرس‌وجو را می‌بیند.

فقط فقط نشانی‌های رسمی Cloudflare با مسیر /dns-query پذیرفته می‌شوند؛ ریزالور دلخواه یا خصوصی اجرا نمی‌شود. CORS یا خطای TLS به معنی فیلترینگ قطعی نیست.

بررسی دسترسی HTTPS به IP

HTTPS با گواهی معتبر همان IP بررسی می‌شود. مرورگر نمی‌تواند IP دلخواه را با نام TLS دامنهٔ پنل ترکیب کند. پاسخ مبهم opaque فقط «سیگنال محدود» است، نه IP تمیز تأییدشده.

سبز فقط با پاسخ قابل‌خواندن و معتبر Cloudflare Trace؛ نارنجی صرفاً سیگنال مرورگر. قرمز یعنی آزمون تأیید نشد، نه اثبات قطع IP. پینگ تونل و اسکن پیشرفته در پنل جدا هستند.

WireGuard؛ آزمون واقعی، بدون پینگ ساختگی

مرورگر معمولی سوکت UDP دلخواه ندارد. WebTransport هم به سرور HTTP/3 سازگار نیاز دارد و جایگزین handshake سرور WARP نیست. این HTML به‌تنهایی پینگ WireGuard نمی‌گیرد.

  1. در کارگاه، فایل حساب WireGuard خودتان را دانلود کنید.
  2. ابزار محلی Node.js همراه سورس را روی سیستم خودتان اجرا کنید؛ کلید خصوصی همان‌جا می‌ماند.
  3. فایل نتیجهٔ JSON را اینجا وارد کنید؛ زمان پاسخ احرازشده و خطاها جدا نمایش داده می‌شوند.
npm ci
node tools/endpoint-scan.mjs account.conf

راهنمای کامل: tools/README_FA.md در سورس رسمی NightLine. ابزار محلی به Python یا نصب درایور نیاز ندارد. این بخش گزارش ابزار محلی شما را می‌خواند، نه گواهی مستقل یا آزمون UDP مرورگر.

موفقیت یک handshake، تأیید سرعت، پایداری، اثربخشی DPI یا عبور کامل اینترنت نیست. فقط نتیجهٔ خودتان را وارد کنید؛ این ابزار MASQUE را نمی‌سنجد.
