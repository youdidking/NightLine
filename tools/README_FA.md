# آزمون مقصد WARP از اینترنت خودتان

**این ابزار Node.js است؛ Python، دسترسی مدیر، نصب درایور و سرور محلی نمی‌خواهد.**
فقط روی کامپیوتر خودتان اجرا کنید؛ کلید خصوصی حساب در همان کامپیوتر می‌ماند. Worker این آزمون را اجرا نمی‌کند.

۱. Node.js نسخهٔ ۲۲ یا جدیدتر را نصب کنید. ZIP نایت‌لاین را از حالت فشرده خارج کنید؛ در پوشه‌ای که `package.json` دارد ترمینال باز کنید و یک بار بزنید:

```sh
npm ci
```

۲. در کارگاه اتصال، حساب WireGuard شخصی بسازید/وارد کنید. فایل `.conf` یا پشتیبان JSON کارگاه را دانلود و مثلاً `account.conf` نام‌گذاری کنید. حساب را هم‌زمان در برنامهٔ دیگری فعال نکنید؛ تغییر مسیر roaming می‌تواند آزمون را مخدوش کند.

۳. بدون فهرست دلخواه، ابزار از `tools/endpoints.txt` استفاده می‌کند:

```sh
node tools/endpoint-scan.mjs account.conf
```

یا فهرست قابل‌ویرایش کارگاه را با نام `endpoints.txt` در پوشهٔ پروژه ذخیره کنید:

```sh
node tools/endpoint-scan.mjs account.conf endpoints.txt endpoint-results.json
```

۴. نتیجهٔ `endpoint-results.json` را در بخش «یافتن مقصد» کارگاه وارد کنید؛ یکی از نتیجه‌های پاسخ‌دار را انتخاب و «اعمال مقصد به کانفیگ» را بزنید. متن را کپی یا دانلود کنید و در کلاینت خودتان تست نهایی بگیرید.

## معنی نتیجه

- موفق یعنی پاسخ Noise_IKpsk2 با کلید واقعی سرور رمزگشایی و احراز شده است؛ HTTP، ICMP، cookie و بستهٔ نامعتبر موفق نیستند.
- عدد، زمان **یک handshake** است؛ سنجش سرعت، پایداری، UDP داده یا اینترنت انتها‌به‌انتها نیست. برای مقایسهٔ بهتر دوباره در زمان مناسب آزمون کنید.
- timeout فقط یعنی پاسخ معتبر در ۲٫۵ ثانیه نرسید؛ نتیجهٔ شکست، عدد پینگ صفر نمی‌گیرد.
- فهرست پیشنهاد است، نه IP تمیز تضمینی برای ایران. تنها آدرس IPv4 صریح در محدوده‌های WARP `162.159.192/193/195/196.x` و پورت معتبر پذیرفته می‌شود؛ CIDR و نام دامنه اجرا نمی‌شوند. حداکثر ۶۴ مقصد، ترتیبی، بدون تکرار خودکار؛ با Ctrl+C متوقف می‌شود.
- ابزار مختص WireGuard/WARP است، نه MASQUE. تنظیم junk/CPS را داخل بسته‌های آزمون اعمال نمی‌کند؛ handshake استاندارد سازگاری سرور را بررسی می‌کند.
- JSON نتیجه کلید/توکن ندارد؛ پنل گزارش واردشدهٔ خود شما را نمایش می‌دهد، نه گواهی مستقل امضاشده. فایل نتیجه را از دیگران نگیرید.
- فایل حساب، کلیدها و پشتیبان محرمانه‌اند؛ پس از استفاده امن نگه دارید/پاک کنید. موفقیت ثبت API به‌معنی موفقیت اتصال نیست.
